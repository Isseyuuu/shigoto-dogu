# note-monetization/CLAUDE.md

このディレクトリは **note.com での有料記事・有料マガジンによる収益化** を
目的とした、shigoto-dogu サイト本体(`index.html` / `articles/` 等)とは
別プロジェクトである。媒体も収益構造も異なるため、ここに独立した運用ルールを置く。

ルート直下の `CLAUDE.md` にある体制(Manager/Codex/Claude Code の役割分担)、
Codex への伝達方法(stdin 経由・複数行を1行目で切り捨てない)、
「修正しました」を成果物と見なさず差分で確認する原則、検証スクリプト通過を
品質の根拠にしない原則は、このディレクトリでもそのまま適用する。
以下は note 有料記事に固有の追加ルールのみを記す。

## 位置づけ

- 媒体は note.com。HTML サイトではないため、成果物は Markdown/テキストの
  記事原稿であり、公開は Manager が note.com のエディタに貼り付けて行う。
  自動投稿・API 経由の公開は行わない。
- **ジャンル・ペルソナは Manager が決める。** エージェントが「これは需要が
  なさそう」「初心者には難しそう」等の理由で候補を勝手に絞り込んではいけない
  (ルート CLAUDE.md の同種の事故を参照)。
  2026-08-27 時点でジャンル未確定。`research/` に調査結果と候補を記録し、
  Manager の選定を待ってから `drafts/` の執筆に入る。

## 情報商材化させない(最重要)

調査の結果、note の「有料記事で稼ぐ」系ジャンルは、**「note で稼ぐ方法」を
売るための note が上位検索結果の大半を占める自己言及的な構造**になっている
ことが分かった(`research/2026-08-27-market-research.md` 参照)。誇張された
収益額や再現性の怪しい成功談が多数出回っている。このリポジトリでは以下を
厳守する。

- 実体験・一次情報に基づかない収益額を書かない。書く場合は前提条件
  (期間・母数・再現性の有無)を明記する。
- 「誰でも」「絶対」「必ず稼げる」等、再現性を保証する表現を使わない。
- 他人の収益実績や体験談を裏取りなしに引用・転載しない。
- 「note で稼ぐ方法を教える note」のような自己言及的なジャンル自体は、
  既に供給過多かつ信頼性が低い領域として、有力候補から外して Manager に提示する
  (ただし最終判断は Manager が行う)。

明記し、`FACTCHECK` 未処理のまま原稿を確定しない。

## ディレクトリ構成

- `research/` — 市場調査・ジャンル候補・裏取り済みデータ(このファイル群が
  Manager の意思決定材料になる)
- `drafts/` — 記事原稿(Markdown)。ジャンル確定後に着手。公開前は
  FACTCHECK 未処理ゼロを確認する
- `published/` — 実際に note.com へ公開した原稿の控え(公開日・URL付き)

## 公開前チェック(note 版)

1. 収益額・成功率などの断定表現に根拠があるか、前提条件を明記しているか
2. 価格・統計に FACTCHECK 未処理が残っていないか
3. 有料エリア(「ここから先は」)の分割位置が、無料部分だけで記事の価値が
   判断でき、かつ核心(再現性のある具体的な方法・データ)は有料部分にある
   構成になっているか
4. 特商法・景品表示法上の懸念がないか(Manager 最終確認)
5. 他人の実績・体験談を裏取りなしに引用していないか
