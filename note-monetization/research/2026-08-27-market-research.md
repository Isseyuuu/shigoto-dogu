# 市場調査メモ(2026-08-27)

note.com の有料記事・有料マガイン市場で「誰が何にお金を払っているか」を
Web検索で調査した一次まとめ。ジャンル選定は Manager が行うための材料であり、
このメモ自体はジャンルを決定しない。

## 調査の前提と注意(重要)

検索結果の上位は、その多くが **「note で稼ぐ方法を売るための note」** という
自己言及的な構造だった。「note 有料記事 稼ぐ ジャンル」等で検索すると、
上位に出てくるのは実際に売れているジャンルの客観的分析ではなく、
「これを読めばあなたも稼げる」と謳う情報商材的な記事そのものであることが多い。
そのため、以下の「売れ筋」情報は **業者・発信者側の自己申告** が混ざっており、
金額(月◯万円稼いだ等)はそのままでは裏取りできていない。数値は参考程度に扱い、
実際に記事へ書く際はルート CLAUDE.md の数値監査ルールに従うこと。

note公式(note株式会社)が約30万件の有料記事(2024年12月〜2025年11月)を
分析したというデータが複数の二次情報源で言及されており、そこでは
「実用系1,800円・読み物系980円」が売上上位20%の価格帯とされている。
ただし一次ソース(note.jp / prtimes.jp)はこのネットワーク環境からアクセス
できず(egress block)、**直接確認はできていない**。複数の独立した発信者が
同じ調査名・期間を引用している点で一定の信頼はあるが、Manager の判断に
使う前に、可能であれば別経路で note 公式発表を直接確認することを推奨する。

## 検索から見えた「今お金が動いているジャンル」

複数ソースで共通して挙がった、有料 note で売れているとされるジャンル。
括弧内は典型的な切り口。

1. **AI活用・AI副業**(ChatGPT等の業務活用、プロンプト集、AIでの記事量産法)
   → 供給過多かつ自己言及的(「AIで稼ぐ方法をAIで書いて売る」)。参入障壁が低く
   コモディティ化が早い。差別化なしでの参入は非推奨。
2. **副業の実体験**(「副業で月◯万円」「会社にバレない副業」)
   → 需要は大きいが、金額訴求型は誇張との区別が読者側にもつきにくく、
   プラットフォーム的にも供給過多。
3. **キャリア・転職の実体験**(「年収を100万円上げた転職術」「未経験からIT業界へ」)
   → 具体的な業界・職種を絞った実体験は差別化しやすい。
4. **SNS運用ノウハウ**(X/Instagram/TikTok のフォロワー・バズらせ方)
   → 再現性を示せるかが鍵。競合非常に多い。
5. **投資・資産形成**
   → 法令・数値の扱いが厳格に問われる領域(金融商品取引法等)。ルート
   CLAUDE.md の数値監査に加え、投資助言に該当しない書き方の確認が要る。
6. **恋愛・婚活**
   → bridal-note(別リポジトリ)と読者層が近く、社内の別事業と競合しうる。
7. **デザイン・クリエイティブ実務**(Canva テンプレート、写真・動画編集、
   ロゴ制作の実務ノウハウ)
   → 具体的な成果物(テンプレート配布込み)にできると単価を上げやすい。
8. **プログラミング・IT実務の実体験**

## 価格帯の目安(要裏取り継続)

- エッセイ・読み物・体験談: 300〜1,000円程度
- ライフハック・趣味: 500〜1,500円程度
- ビジネス・専門性の高い実用コンテンツ: 1,500〜3,000円程度
- 上記は複数の二次情報源が共通して挙げる目安であり、note 公式一次データでの
  直接確認はまだ。

## shigoto-dogu の既存資産との接続で検討できる候補

このリポジトリは元々「仕事道具(会計・確定申告・業務ツール)」を扱っており、
すでに一次情報の裏取り体制(Claude Code によるファクトチェック)がある。
以下は調査から見える「今お金が動いている領域」と、この資産の接続候補
(あくまで候補であり、選定は Manager が行う)。

- フリーランス・個人事業主の確定申告/会計ソフト選びの実務ノウハウ
  → 既存サイトの専門性と直結し、他の「AIで稼ぐ」系ジャンルと違って
  一次情報での裏取りがしやすい。ただし無料記事(shigoto-dogu 本体)との
  棲み分け(無料で何を出し、有料で何を出すか)を最初に設計する必要がある。
- フリーランスの働き方・独立の実体験(税務以外の側面: 営業・単価交渉・
  保険や年金の扱いなど)

## 未検討で追加調査が要る観点

- note.com の販売手数料率・決済手段・特商法上の扱い(CLAUDE.md に
  FACTCHECK として記録済み)
- 想定読者が実際にどのくらいの母数いるか(competitor の記事のスキ数・
  コメント数などの定量指標を後続調査で確認)
- 定期購読マガジン形式 vs 単発有料記事、どちらが今回の候補ジャンルに
  向くか
